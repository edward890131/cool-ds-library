# 示範照片（元件庫用）

設計團隊提供的示範照片，給元件庫的牌卡與圖片類元件使用（person-card、profile-card、widget-card 頭像等）。
gallery.html 內以壓縮後的 data URI 嵌入（離線與 Claude 預覽可用）；這裡保留原檔，之後要換圖或重新裁切從這裡取。

| 檔案 | 用途 |
|---|---|
| sunglasses-portrait.webp | person-card 主照片、頭像 |
| city-monochrome.webp | 頭像、展開卡／滑卡示範 |
| white-suit-night.webp | 頭像、展開卡／滑卡示範 |
| field-grey-suit.webp | 頭像、滑卡示範 |
| dusk-white-set.webp | 頭像、展開卡／滑卡示範 |
| office-window.webp | 首頁使用回饋段落背景（使用者提供，2026-11-04） |

專案自己的品牌素材請放 `projects/<name>/assets/`（CLAUDE.md 鐵則 4），不要放這裡。
